AlpNAS Installer

Installiere AlpNAS direkt aus dem Live-System auf eine lokale SSD oder HDD. Der Ziel-Datentraeger wird dabei neu partitioniert, Alpine wird klassisch auf die Platte installiert und GRUB fuer BIOS und UEFI eingerichtet. Auf installierten Systemen erscheint dieses Modul nicht mehr.

Modus Live-System
Erkannte Ziele 0
Status Bereit

Ziel-Laufwerk

Waehle die SSD oder HDD, auf die AlpNAS installiert werden soll.

Installationsprofil

Die Installation verwendet ein klassisches Festplatten-Layout: BIOS-Boot, EFI und Root-Dateisystem.

Partition 1BIOS boot (ca. 2 MiB)
Partition 2EFI System Partition (512 MiB, FAT32)
Partition 3AlpNAS Root (Rest der Platte, ext4)
BootloaderGRUB fuer BIOS und UEFI
Das gewaehlte Laufwerk wird komplett geloescht. Vorhandene Partitionen und Daten darauf gehen verloren.
